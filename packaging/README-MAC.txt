Barehands (New Engine) 1.1.0 - macOS

WHAT YOU NEED
  Python 3. macOS may offer to install it (Command Line Tools) the
  first time you run python3; python.org also works.

INSTALL
  1. Unzip, then drag BarehandsNew.app into your Applications folder.
  2. First launch: right-click the app and choose Open (the app is
     unsigned, so a plain double-click is blocked by Gatekeeper the
     first time). After that it opens normally.

The app starts a small local server and opens the board in your
browser at http://127.0.0.1:8794/stage.html - allow camera access
there. The runnable copy and your board state live in
~/Library/Application Support/BarehandsNew.

UNINSTALL
  Delete BarehandsNew.app from Applications and the folder above.
